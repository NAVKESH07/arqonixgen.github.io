What we build

Chips that compute, connect, and protect

AI in the data centre needs more than fast processors. It needs fast links between chips, and hardware it can trust. We build all three.

AI processors

Processors designed around AI workloads, so models train and run faster on less power.

Die-to-die interconnect

High-speed, low-power links between dies in one package, so large AI systems can be built from chiplets.

Security chips

Security built into silicon for data centres, protecting keys, firmware, and data from the hardware up.
